# UAT v0.4.0: Text, weather & countdown

**Status:** accepted 2026-10-07 (round 2) · round 1 rejected → bugs #106 #107 #108 (fixed)
**Build:** `main` @ `fb22fc8` (round 2; round 1: `e24e1ce`) · **UAT issue:** #105 · **Issues:** #28 #30 #98 #33

## Preconditions
- Build installed (see `docs/uat/README.md`), Timebox Evo switched on, 1-2 m from the Homey, the Divoom phone app closed
  and the Evo not connected to any phone (it accepts one connection).
- The device is paired (a v0.3.0 device is fine and is kept; the new cards and settings appear without re-pairing). Homey
  app language English; repeat UAT-14 with German. Homey location and time zone set correctly (needed for UAT-6).
- A webcam or your eyes on the Evo display.
- Create a test Flow with a button trigger (or use the "Test" button of each card in the Flow editor) for each action card.
- Cases marked `[auto]` can be driven by the tester agent (Flow cards run via `scripts/homey-api.sh`, device settings via
  the API, webcam via `scripts/hw-snap.sh`) in a `homey app run` (DEBUG) session. Pairing is always by hand. Cases without the
  mark are manual (Flow editor UI, texts, the Homey location, buttons on the device).
- Colours, scrolling and animations are judged by eye; the exact look of the pages may differ from the descriptions.

## Known open issues (not failures of this round)
- Flow argument validation (UAT-6, owner remark round 2): an out-of-range or too long value cannot be blocked when the Flow is
  saved. Homey text arguments have no length limit, and tags/variables only get their value at run time; the error appears when
  the card runs ("Test" or a real run). Number arguments are limited by min/max in the Flow editor. Homey limitation, accepted.
- Native text (#28): at most 64 characters are shown (a longer text fails the action with a readable error, UAT-6), emoji and characters the Evo font cannot draw
  are removed (and not counted). A text that still runs on the device after an app restart is not known to the app: use "Stop text" or any
  mode change. A mode change made at the device (buttons, Divoom app) is not noticed; the duration timer then sends a
  harmless stop.
- Weather (#30): the clock page flags "Show weather" / "Show temperature" are not switched on by the app; switch them on in
  the device settings. A weather value set while the panel is off or a text runs is sent by the next 60 s check, not at once.
  Only degrees Celsius are supported (Fahrenheit: #96).
- Weather (#98): each Flow action sets one part. A part that was never set is shown as 0 °C / clear until it is set (or
  Open-Meteo sets both), so switch off the clock page of the part you do not feed. Open-Meteo overwrites both parts at each update.
- Countdown (#33): a mode change, a text or power off only hide a running countdown; it keeps running and its end display
  (`00:00`, a few seconds) appears later, also lighting a panel that is off. A stop cannot end a countdown while it is hidden.
  There is no "countdown ended" trigger yet (#101).
- Clock animation pages (#106): the setting writes a persistent flag of the Evo (the Divoom phone app shares it), so the Evo keeps
  the last value also without the Homey. The app sends it when the clock is entered or a clock setting changes; changed while another mode
  is shown, it applies at the next entry into the clock. Its effect in custom pages or during a text was not measured (in lighting it changes nothing).
- #62 Changing the brightness while the panel is off lights the panel again. Expected.

## Test cases
### UAT-1 New cards and settings are present (#28 #30 #98 #33 #106)
1. Open the Flow editor, add an action, choose the Timebox device.
2. Open the device settings (wrench).
3. Switch the mode to Clock with "Show animation pages" off (the default) and watch the Timebox for 2 minutes.
4. Switch "Show calendar" on (still without animation pages) and watch for 2 minutes. Then switch "Show animation pages" on.
**Expected:** The actions "Show text", "Stop text", "Set temperature", "Set weather", "Start countdown", "Stop countdown" exist
(next to the 0.3.0 ones). The settings show the clock group with "Show weather", "Show temperature", "Show calendar", "Show animation pages" (off by default, #106), and a
"Weather" group with "Automatic weather from Open-Meteo" and "Update interval" (15 / 30 / 60 minutes, default 30). The app
asks for no new permission beyond location access for Homey's own location. The tile still works (power, brightness, colour, mode).
Step 3: a static clock, the time stays on screen, no heart, duck, ghost or cat pictures appear, and the tile stays on Clock.
Step 4: with "Show calendar" only the time and date pages alternate; after "Show animation pages" is switched on the gallery pictures come back between the clock pages within about 2 minutes (the setting is applied at once while the clock is shown).

### UAT-2 Show text, basic (#28) [auto]
1. Flow action "Show text": text `Hello Homey`, colour white, background black, speed Normal, duration `0`. Run it.
**Expected:** Within about 2-3 s the Evo scrolls "Hello Homey" in white on black, right to left, and loops it. The tile and the
mode picker do not change (the text is not a mode). The action returns without an error.

### UAT-3 Text colours, speeds and Flow tags (#28) [auto]
1. Run "Show text" with text `Colour test`, colour red, background blue, speed Slow. Then Fast. Then Normal.
2. Use a Flow tag for the text (for example a number or text tag from another card, or the Homey time tag).
**Expected:** The new text replaces the running one at once. Colours match (red letters on blue), Slow is clearly slower than
Normal, Fast clearly faster (roughly 3 / 5 / 10 columns per second). The tag value is shown as text.

### UAT-4 Text duration and Stop text (#28) [auto]
1. Run "Show text" with duration `10`. Time it.
2. Run "Show text" with duration `0`, wait 10 s, then run "Stop text".
**Expected:** 1. After about 10 s the text disappears and the Evo returns to the previous mode (clock, lighting or custom page).
2. The text runs until "Stop text" and then disappears. Running "Stop text" with no text shown does nothing visible and is no error.

### UAT-5 Text is ended by a mode change or power off (#28) [auto]
1. Start a text with duration `0`. Select another mode on the tile (for example Lighting).
2. Start the text again and switch the tile off.
3. Start the text again, then run "Show clock".
**Expected:** Each time the text ends at once and the new mode or the dark panel is shown; no text comes back later.

### UAT-6 Text limits and invalid input (#28) [auto]
1. "Show text" with a very long text (more than 64 characters, for example 80 letters).
2. "Show text" with emoji only (`😀🎉`), then with `Hi 😀 there`.
3. "Show text" with an empty text, and a duration above 3600 (if the field accepts it; a number variable holding 4000 gets past the editor).
**Expected:** 1. The action fails with the readable error "The text is too long: 80 characters. The Timebox shows at most 64 characters (emoji are not counted)." (in the language of the Homey); nothing is sent and the display stays (a running text keeps running). 2. Emoji only fails with the readable error "The text is empty
after removing the characters the Timebox cannot show (such as emoji)." and the display stays; with mixed text the emoji
are dropped and "Hi  there" (or "Hi there") scrolls. 3. A readable, localised error, nothing is sent, the current display stays. With German as the app language the duration 4000 fails with "Dauer (s): 4000 liegt außerhalb des erlaubten Bereichs von 0 bis 3600." (English: "Duration (s): 4000 is out of range. Allowed is 0 to 3600.").

### UAT-7 Temperature from a Flow (#30 #98) [auto]
1. Device settings > Clock: switch on "Show temperature" and save. Wait for the clock rotation (the pages change every few seconds).
2. Run "Set temperature" with `21`. Later `-5` and `-0.4`.
**Expected:** Within a few seconds the temperature page of the clock rotation shows 21 °C, later -5 °C, and 0 for `-0.4`
(rounded to whole degrees). The clock itself is not disturbed. A value of `150` (via a number variable; the editor rejects a typed 150) fails with "Temperature (°C): 150 is out of range. Allowed is -99 to 99." and shows nothing new.

### UAT-8 Weather condition from a Flow (#30 #98) [auto]
1. Device settings > Clock: switch on "Show weather" and save.
2. Run "Set weather" with each of Clear, Cloudy, Thunderstorm, Rain, Snow, Fog, one after the other, and watch the weather page.
**Expected:** The weather page shows a matching icon each time (sun, cloud, lightning, rain, snow, fog); the temperature
shown on the page stays as set in UAT-7 (the cards change only their own part).

### UAT-9 Both parts are independent (#98) [auto]
1. Run "Set temperature" `15`, then "Set weather" Snow, then "Set temperature" `3`.
**Expected:** After the second run the page shows snow with 15 °C; after the third snow with 3 °C. The condition is not reset
by the temperature card and the temperature is not reset by the weather card. (For a device that never had a value, the
missing part shows 0 °C / clear.)

### UAT-10 Automatic weather from Open-Meteo (#30)
1. Device settings > Weather: switch on "Automatic weather from Open-Meteo", interval 15 minutes, save. Make sure "Show weather"
   and "Show temperature" are on.
2. Wait up to about a minute.
**Expected:** The weather page shows the current weather type and the temperature page the current outside temperature for
your location (compare with a weather app, within 1-2 degrees). The hint mentions Open-Meteo (CC BY 4.0). Switching the
setting off stops further updates; a Flow value still works. Without internet the Evo is not disturbed and no error toast appears.

### UAT-11 Weather survives power cycle and panel off (#30)
1. With a weather set (UAT-9), switch the tile off, run "Set temperature" `7`, switch the tile on.
2. Unplug the Evo for 10 s, plug it in, wait until the tile is available again (up to ~3 min).
**Expected:** 1. After switching on (at most one 60 s check later) the temperature page shows 7 °C. 2. After the reconnect the
Evo shows the last set condition and temperature again without running a Flow.

### UAT-12 Start countdown (#33) [auto]
1. Flow action "Start countdown" with 0 minutes and 40 seconds. Run it from the clock.
2. Repeat from the lighting mode, and once while the tile is off.
**Expected:** The Evo shows an hourglass with minutes (top) and seconds (below) counting down once per second. The tile and
mode picker stay unchanged. At 00:00 the end display (colours swapped) shows for a few seconds, then the Evo returns to the previous view
(clock, lighting colour). Started while off, the panel lights and shows the countdown; after the end it stays lit with the last mode.

### UAT-13 Stop countdown, restart and limits (#33) [auto]
1. Start a countdown of 5 minutes, wait 5 s, run "Stop countdown".
2. Start a countdown of 20 s, 3 s later start one of 8 s.
3. Start `99` minutes `59` seconds, then stop it. Start 0 minutes 0 seconds. Start `100` minutes (if the field accepts it).
4. Start a countdown, then run "Show text" (duration 0) and "Stop text".
**Expected:** 1. The digits disappear and the Evo shows the mode it had before (clock stays clock, lighting stays lighting) within
a few seconds. 2. The second start replaces the first (about 6 s left right after) and the end display comes once. 3. 99:59 counts
down and the stop works; 0:00 fails with "Set a countdown of at least 1 second." and 100 minutes with a readable range error;
nothing is started in both cases. 4. The text replaces the countdown; after "Stop text" the mode is shown, the countdown is not
restored (it keeps running hidden and its end display flashes at the original end time: a known limit).

### UAT-14 German texts (#28 #30 #98 #33)
1. Set the Homey app language to German; open the Flow cards and the device settings.
**Expected:** "Text anzeigen" (placeholder "Hallo Homey", duration "0 = bis zum Stoppen", speeds Langsam / Normal / Schnell), "Text beenden",
"Temperatur setzen", "Wetter setzen" (Klar, Bewölkt, Gewitter, Regen, Schnee, Nebel), "Countdown starten" ("... über 5 Min. 0 s ..."), "Countdown beenden";
settings group "Wetter" with "Automatisches Wetter von Open-Meteo" and "Aktualisierungsintervall" (Alle 15/30/60 Minuten); the hints are German.
No raw keys and no English leftovers. Error texts (UAT-6, UAT-13) are German as well.
2. "Text anzeigen" with the duration taken from a number variable that holds 4000 (a logic variable or a number tag; the editor only checks typed values).
**Expected:** The action fails with "Dauer (s): 4000 liegt außerhalb des erlaubten Bereichs von 0 bis 3600.", nothing is sent and the display stays (#108).
3. "Text anzeigen" with a text of 80 letters; "Temperatur setzen" with a number variable holding 150; "Countdown starten" with minutes 100 (variable).
**Expected:** 3. Readable German errors, no English text and no raw key: "Der Text ist zu lang: 80 Zeichen. Die Timebox zeigt höchstens 64 Zeichen (Emojis zählen nicht).", "Temperatur (°C): 150 liegt außerhalb des erlaubten Bereichs von -99 bis 99." and "Minuten: 100 liegt außerhalb des erlaubten Bereichs von 0 bis 99.". Nothing is sent. Then switch the Homey language back to English and restart the app (Homey > Apps > Divoom Timebox > Restart): the same inputs give the English texts.

## Edge cases
### UAT-15 Device unreachable: the new actions fail readably (#28 #33 #98)
1. Switch the Evo off, wait until the tile is unavailable (about 30 s).
2. Run "Show text", "Stop text", "Start countdown", "Stop countdown", "Set temperature", "Set weather".
**Expected:** No hang. Text and countdown cards fail with "The Timebox is not connected right now. Try again in a moment."
"Set temperature" and "Set weather" succeed without an error (the value is kept). After switching the Evo on it recovers by
itself and shows the last weather (UAT-11); a "Stop text" that was queued while it was off is done after the reconnect.

### UAT-16 Quick successive actions (#28 #33)
1. Run "Show text" and at once "Start countdown" (two test presses within a second), then "Show text" twice with different text.
**Expected:** The newest action wins (countdown replaces the text; the second text replaces the first). No error toast, no
stuck half-drawn text.

## Regression smoke (v0.2.0 and v0.3.0, accepted)
- Pairing (v0.2.0): tile available within ~45 s with on/off, brightness, colour and mode.
- Availability: switch the Evo off for 1 min and on again; "Timebox disconnected"/"connected" fire once each, the tile recovers by itself.
- Mode picker (v0.3.0): Clock, Lighting, Custom switch the Evo within ~2 s; "Show clock" with a style and colour, "Set lighting", "Show custom page" work.
- Clock settings (v0.3.0): changing "Clock style" while the clock is shown updates the Evo at once; "Set the time automatically" corrects a wrong time after a reconnect.
- Brightness slider and on/off tile follow the Evo without an error toast.
